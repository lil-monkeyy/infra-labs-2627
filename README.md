This repository contains the lab assignments for the course Infrastructure Automation starting academic year 2026-2027. The course is part of the [Bachelor Applied Computer Science programme](https://www.hogent.be/opleidingen/bachelors/toegepaste-informatica/) at [HOGENT](https://www.hogent.be/).

The goal of these assignments is to get familiar with concepts like Infrastructure as Code, CI/CD, configuration management, monitoring, container orchestration, etc.

This repository is structured as follows:

- [assignment](assignment/): contains the lab assignments and additional lab material when applicable.
- [labenv](labenv/): contains the code for setting up the virtual environment you will build throughout the labs.
- [report](report/): you will use this directory to keep your lab reports and additional notes.

The lab environment code is based on the [vagrant-shell-skeleton](https://github.com/bertvv/vagrant-shell-skeleton) project that contains scaffolding code for setting up a local environment consisting of multiple virtual machines powered by [Vagrant](https://vagrantup.com).
